- Sinh viên: Nguyễn Ánh Thư
- MSSV: 25100730
- Trường: Trường Đại học Y Dược, Đại học Quốc gia Hà Nội

## Cấu trúc

- `index.html`: khung trang chính.
- `css/style.css`: theme Clinical Learning Journal và responsive layout.
- `js/script.js`: dữ liệu 7 bài tập, hồ sơ học tập, modal chi tiết.
- `files/`: 7 PDF bài tập đã chuẩn hóa tên từ `tuan1.pdf` đến `tuan7.pdf`.
- `images/favicon.svg`: favicon clipboard và nhịp tim.
